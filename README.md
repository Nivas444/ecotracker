# SortyX EcoTracker — Smart Waste Management Dashboard

> **A next-generation, AI-ready waste tracking platform that transforms how hotels and tourist locations manage, track, and monetise waste — from collection to compliance.**

---

## What Is SortyX EcoTracker?

SortyX EcoTracker is a **real-time Smart Waste Management Dashboard** designed for hotels, resorts, and tourist locations. It provides end-to-end visibility into waste — from the moment it's collected in smart bins or registered by drivers, to its final processing destination — while automatically generating ESG compliance reports.

The system bridges the gap between **IoT hardware** (smart bins with sensors) and **business intelligence**, giving facility managers, sustainability officers, and stakeholders a single platform to monitor, optimise, and report on waste operations.

---

## How It Works

### The Complete Flow

```
Hotel / Location (Checklist Stops)
       ↓
Driver Portal (logs collection → batch created with status 'CREATED')
       ↓
Admin Dashboard (tracks batch → marks 'DELIVERED' → verifies at facility)
       ↓
Recycler Connectivity (manually registered external facility buyers)
       ↓
Compliance & ESG Report (PDF/CSV auto-generated, audit-ready)
```

## Key Features

### 1. Visual Overview & Analytics Dashboard
- **Compact Layout** — Side-by-side horizontal grid rows to maximize workspace and reduce vertical scrolling.
- **Environmental Metrics** — CO₂ saved (calculated using the updated **3.0x** emission multiplier for mixed recycled plastics), waste diverted from landfill, and recycling rates updated in real time.
- **Verification Summaries** — Recharts donut chart visualization showing verified vs pending shipment ratios.
- **Delivery Statistics** — Compact progress indicators illustrating batch volumes across all operational stages (`CREATED`, `DELIVERED`, `VERIFIED`).
- **Audit Feed** — Chronological log of operational activities with monochrome icons.

### 2. Driver Portal & Dashboard (New!)
- **Driver Profile** — Dedicated section tracking driver name, experience, assigned vehicle (`GC-2045`), active route, and status.
- **Today's Assignment** — Interactive stop checklists (e.g., Hilton Resort, Secrets Resort, Iberostar) and expected completion times.
- **Collection Form** — Compact form to log waste and plastic weights. Auto-fills driver name, active route ID, status as `CREATED`, and current timestamp.
- **Dynamic Syncing** — Submitting a collection immediately updates the active stops checklist, adds activity log records, and updates the Admin dashboard metrics without page refreshes.

### 3. Refactored PDF Executive Summaries
- **A4 Single-Page Design** — Generated dynamically via `jsPDF` using a clean, report-specific corporate business style. Excludes navigation controls, dropdowns, and buttons.
- **Branding Header** — Embeds base64 Green Carib logo (with vector text fallback) and document detail cards with applied filters.
- **Report Types**:
  - *Operational Reports*: Summarizes completed collections, route dispatch efficiency, delayed routes, and driver performance scores.
  - *Waste Reports*: Summarizes processing residue, recycling rates, and composition matrices.
  - *Sustainability & ESG Reports*: Detailed ledger showing historical CO₂ saved and waste diverted trend data alongside calculation methodologies.

### 4. Excel-Compatible CSV Exports
- **Branding Metadata Header** — Appends spreadsheet-compatible metadata blocks (Company, Platform, Report Type, Generation Date, Generated By) at the top of every generated CSV file, leaving one blank row before the tabular data.
- **Auto-Parsing Prevention** — Formats dates as textual strings (e.g., `29-May-2026 at 03:00 PM`) to prevent Excel from displaying `#######` clipping errors in narrow columns.

### 5. Dedicated Recycler Coordination
- **Separate Operations View** — Managed on a dedicated page in the sidebar navigation instead of mixed into the dashboard.
- **Status & Details List** — View buying prices, currency trend indices (Rising / Falling / Stable), location, and contact information.
- **Shipment Delivery History** — Interactive logs nested under each facility card showing historical batches assigned or delivered to them.

### 6. Dedicated Logistics & Fleet Registry
- **Separate Logistics View** — Managed on a dedicated page in the sidebar navigation.
- **Fleet Operator Cards** — View assigned drivers, experience levels, and vehicle plates.
- **Active Cargo Assignments** — Displays active batches currently in transit under each driver's card.

### 7. Light & Dark Theme Swapping
- **Dynamic Switcher** — Persists preferences to `localStorage` and binds the appropriate styles to the root document.
- **Accessible Toggles** — Easily toggle between themes via a floating icon on the Login page, or a button next to the calendar date in the header bar.

### 8. Role-Based Access Control
- **Admin role** (`greencarib_admin`/`GreenCarib@123`) — full access: register recyclers/drivers, edit history, advance batch statuses (`CREATED` → `DELIVERED` → `VERIFIED`), and export data.
- **Driver role** (`driver_john`/`Driver@123`) — collection operations, stop checklists, and batch creation.

## Demo Walkthrough

1. **Driver Flow**:
   - Log in as `driver_john` (password: `Driver@123`).
   - Check **Today's Assignment** stops checklist.
   - Enter `120` kg total waste and `40` kg plastic for "Hilton Resort" in the **Create Batch** form and submit.
   - Notice the stops checklist marks the Hilton stop as **COLLECTED** and collection stats update instantly.

   - Log out, and log in as `greencarib_admin` (password: `GreenCarib@123`).

   - Click the advance trigger to move it to **Delivered**, and then **Verified** (input verification proofs).
3. **Reports Export**:
   - Navigate to the **Reports** page.
   - Select any tab (Operational, Waste, or ESG) and export to PDF or CSV to verify the new branding formatting.
